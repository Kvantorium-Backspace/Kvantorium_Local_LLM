## 🚀 Быстрый старт

### 1. Подготовь окружение
Убедись, что у тебя установлены:
- `docker` и `docker-compose`
- `npm`, `git`, `python`
- `ollama` (опционально, можно использовать внутри контейнера)

### 2. Клонируй репозиторий
```bash
git clone https://github.com/Kvantorium-Backspace/Kvantorium_Local_LLM.git
cd Kvantorium_Local_LLM
```

### 3. Настрой модель (по желанию)
- Выбери модели на [Ollama Library](https://ollama.com/library)
- Отредактируй файл `./frontend/src/api/ModelsConfig.jsx`

Если используешь облачную модель, авторизуйся:
```bash
ollama login
```
Или если ollama запущена только в контейнере:
```bash
docker-compose exec ollama ollama signin
```

### 4. Настрой `.env` (опционально)
- В `./.env` — URL ollama и параметры модели  
- В `./frontend/.env` — URL бэкенда

### 5. Системный промпт (по желанию)
Отредактируй файл `./ollama/system-prompt.txt` — и модель будет общаться так, как ты захочешь.

### 6. Собери и запусти проект
```bash
docker-compose up --build -d
```
- `--build` — пересобрать контейнеры  
- `-d` — запустить в фоновом режиме

### 7. Установи модели
```bash
docker compose exec ollama ollama pull <название_модели>
```

### 8. Пользуйся!
Чат доступен по адресу:  
👉 `http://localhost`

#### Полезные команды:
- `docker-compose down` — остановить проект
- `docker-compose logs -f` — посмотреть логи  
- `docker-compose exec <сервис> <команда>` — выполнить команду внутри контейнера

## 🧑‍💻 Для разработчиков фронтенда

В файле `./frontend/src/api/index.jsx` описаны хуки и примеры работы с API.

Пример использования в твоём компоненте:

```javascript
import { useChatClient } from './api'
import { MODELS } from './api/ModelsConfig'

export default function MyApp() {
  const { messages, loading, activeModel, setActiveModel, sendMessage, stopGeneration, clearHistory } = useChatClient()

  const handleSend = async () => {
    await sendMessage('Привет!')
  }

  return (
    <div>
      {messages.map((msg, i) => (
        <div key={i}>{msg.role}: {msg.content}</div>
      ))}
      <button onClick={handleSend} disabled={loading}>Отправить</button>
      {loading && <button onClick={stopGeneration}>Остановить</button>}
    </div>
  )
}
```

## 🎯 Цели проекта

### 🟠 Минимально жизнеспособный продукт (MVP)
- Стриминговое общение с LLM  
- Возможность выбора любой модели из библиотеки Ollama  
- Лёгкая смена системного промпта  
- Независимость фронтенда от бэкенда  

### 🟢 Идеальный результат
- Полный запуск через Docker «из коробки»  
- Сохранение истории в сессии  
- Поддержка облачных моделей  
- Гибкая настройка поведения модели  
- Автоустановка зависимостей  
- Несколько режимов работы с бэкендом (с историей / без / стриминг)
